In Path of Exile 2, currency is both money and crafting material. This page explains what each common item does. For what each one is **worth**, always check live prices on poe.ninja. Values change daily.

<CurrencyGrid />

## Crafting orbs

| Currency | What it does |
|---|---|
| <GlossaryTerm id="orb-of-transmutation" /> | Normal → Magic with one modifier |
| <GlossaryTerm id="orb-of-augmentation" /> | Adds a modifier to a Magic item |
| <GlossaryTerm id="regal-orb" /> | Magic → Rare, adding a modifier |
| <GlossaryTerm id="orb-of-alchemy" /> | Normal → Rare with random modifiers |
| <GlossaryTerm id="exalted-orb" /> | Adds a random modifier to a Rare item |
| <GlossaryTerm id="chaos-orb" /> | Replaces one random modifier on a Rare item |
| <GlossaryTerm id="orb-of-annulment" /> | Removes one random modifier |
| <GlossaryTerm id="divine-orb" /> | Rerolls the values of an item's modifiers |
| <GlossaryTerm id="vaal-orb" /> | Corrupts an item with an unpredictable result |
| Orb of Chance | Gives a Normal item a small chance to become a Unique |
| Fracturing Orb | Locks one modifier permanently in place |
| <GlossaryTerm id="mirror-of-kalandra" /> | Creates a copy of an item (extremely rare) |

**Greater** and **Perfect** versions of Transmutation, Augmentation, Regal, Chaos and Exalted Orbs exist. They guarantee higher-tier modifiers and are worth much more.

## Quality and socket items

| Currency | What it does |
|---|---|
| Blacksmith's Whetstone | Adds quality to weapons |
| Armourer's Scrap | Adds quality to armour |
| Arcanist's Etcher | Adds quality to wands, staves and other caster weapons |
| Glassblower's Bauble | Adds quality to flasks |
| Gemcutter's Prism | Adds quality to gems |
| <GlossaryTerm id="catalyst">Catalysts</GlossaryTerm> | Add quality to rings and amulets, boosting a type of modifier |
| Artificer's Orb | Adds a rune socket to equipment |
| Jeweller's Orbs | Add support gem sockets to a skill gem |

## Everyday utility

- **Scroll of Wisdom:** identifies an unidentified item.
- <GlossaryTerm id="gold" />: spent at vendors and on refunding passive points. It can't be traded.

## Which currencies matter for trading

Two currencies set most prices:

- <GlossaryTerm id="exalted-orb">Exalted Orbs</GlossaryTerm> for everyday purchases.
- <GlossaryTerm id="divine-orb">Divine Orbs</GlossaryTerm> for expensive items.

Smaller trades are sometimes priced in Chaos Orbs. Convert between them on the <GlossaryTerm id="currency-exchange" />.

<Callout type="tip">
  Don't use your Exalted Orbs on random crafts while leveling. They're far more useful for buying gear that's already good.
</Callout>
